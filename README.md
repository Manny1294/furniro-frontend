# E-commerce Frontend

A modern and responsive e-commerce frontend built with Vue 3, Composition API, Pinia for state management, Bootstrap for UI, and Vue Router for navigation. This is the frontend part of a full-stack e-commerce application.


## Overview

Furniro is a full-featured furniture store that provides users with a seamless shopping experience, from browsing products to checkout. The application demonstrates modern frontend development practices with Vue 3's Composition API, state management with Pinia, and responsive design with Bootstrap and Sass(BEM.

## Features

Product Catalog - Browse furniture with filtering and search capabilities
Product Details - Detailed view with images, descriptions, and specifications
Shopping Cart - Add, remove, and update quantities with real-time cart totals
Checkout Process - Complete order flow 
Responsive Design - Optimized for desktop, tablet, and mobile devices
Toast Notifications - User feedback for actions using Vue Toastification

## 📦 Technologies Used

- Vue 3 (Composition API)
- Pinia (State Management)
- Vue Router (Client-side routing)
- Axios (API request)
- Bootstrap (Styling)
- Render (Deployment)

## API

- Currently integrated with Fake Store API for product data
- Built with backend-ready architecture (previously connected to custom Node.js/Express API)

## ⚙️ Installation and Setup

### 1. Clone the repository

````bash
git clone https://github.com/Manny1294/furniro-frontend.git
cd furniro-frontend
````

### 2. Install dependencies

````bash
npm install
````

### 3. Run Development server

````bash
npm run dev
````

### 3. Production Build

````bash
npm run build
````
